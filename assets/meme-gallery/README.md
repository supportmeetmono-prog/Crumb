# Official CRUMB gallery — source artwork

This directory holds four original PNG images supplied by the CRUMB creator. No artwork alterations, cropping, or edits are authorized.

Upload exact images to this directory with these filenames:

- `crumb-message-01.png` — CRUMB seen from behind, holding a message toward Earth
- `crumb-message-02.png` — CRUMB in profile holding the Martian map
- `crumb-message-03.png` — CRUMB on a Martian ridge under a starry sky
- `crumb-message-04.png` — CRUMB facing camera with the message document

All assets should be 1030 × 1536 px as provided in the source conversation. The website's Meme Lab download buttons reference these exact paths and download each unchanged PNG.

**Do not merge this feature branch before the actual four PNG assets are present**: the markup references the files and would otherwise display broken images.
